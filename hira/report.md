## 오류 원인 및 조치
### 1. 의료 MCP 실행 전 Google 인증 오류 — HIRA 실행 차단 해결
- 기존 공유 환경 준비 스크립트가 근무표용 Google OAuth `TOKEN_INFO` 검사를 매번 수행함.
- 응답 HTTP 400으로 준비 단계가 종료돼 의료 MCP 검증에 도달하지 못함.
- HIRA와 무관한 인증 검사에 대한 의존성을 전용 환경 분리로 제거함.
- HIRA 재실행에서 준비 단계와 모델 실행 성공 확인.
- Google 토큰 오류 자체의 세부 원인·토큰 유효성은 미확인. 근무표 환경의 인증 복구를 완료했다고 주장하지 않음.

### 2. Legacy Codex Cloud MCP 미노출 — 참고, 필수 범위 제외
- 정상 실행되는 진단용 MCP를 사용자 `config.toml`에 등록함.
- 설정 존재, Python 실행 파일과 진단 프로그램 존재 확인.
- 같은 클라우드 컨테이너에서 `initialize`, `tools/list`, `tools/call` 정상 응답 및 종료 코드 0 확인.
- 현재 모델 도구 목록에는 진단 도구와 두 의료 MCP가 모두 없음.
- 고장 위치는 서버 프로세스보다 **클라우드 실행기의 도구 등록·연결 단계**로 좁혀짐.
- 인터넷 없이 동작하는 진단에서도 미노출됐으므로 외부 의료 API 연결 실패와 구분함.
- 일반 명령 실행을 통한 진단 성공을 네이티브 MCP 호출 성공으로 대체하지 않음.
- 이 구형 경로를 별도로 사용할 경우에만 연결 기능 확인이 필요함. 현재 사용 목표의 필수 조건은 아님.

### 3. MCP 서버 호환성 및 API 연결 — 수정·검증 완료
- 병원 비급여: `mcp==1.30.0`, `fastmcp==2.14.7` 호환 버전 고정 및 읽기 전용 도구 메타데이터 추가.
- 한국 공공의료: 공공데이터 API 주소를 HTTPS로 수정, 의존성 취약점 8건→0건, 읽기 전용 메타데이터 추가.
- 필요한 공공데이터 API 8개 활용신청 승인 후 9개 조회 영역 검증 완료.
- 통계 기본 연도 2023의 빈 결과와 API 오류를 구분함. 2024년 명시 조회 성공 확인.
