제공 원문의 나이·활동기간·라이브 현황을 보존한 디자인 자료. 메가데스 외 전체 사실 검증 전. 사진은 초기·전성기와 최근 활동기의 대비이며, 2026년 촬영 또는 현재 전체 라인업을 뜻하지 않음. 캡션의 ‘보도사진·홍보’는 자료 공개 시기이며 촬영연도와 다를 수 있음. 연도가 없는 사진의 정확한 촬영일은 미확인.

메가데스 활동기간: 머스테인 1983–2002·2004–현재 / 로멘조 2006–2010·2021–현재(투어 포함). 중단 기간 제외, 연도 차이 합산의 근삿값. 기존 원문 근거 표기: Megadeth 공식 프로필·연혁 (2026-10-04 확인).

사진·앨범 커버의 권리는 각 원출처에 있음. 외부 이미지 로딩에는 인터넷 연결 필요.
