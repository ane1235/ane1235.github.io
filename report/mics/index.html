등록범위 확대·분모 변화·도입기관 증가를 함께 확인.

한국에는 조건부 경로로 적용

국내 수술량·적격비중·채택률을 분리. 외국 비율의 직접 대입 방지.

근거 범위는 자료의 대표성 분류임. 임상효과의 근거등급을 의미하지 않음.

정의·분모·한국 적용 원칙

겹치는 개념을 분리하여 기록

MIDCAB / 다혈관 MICS-CABG

MIDCAB은 문헌마다 범위가 다름. 단일 LIMA–LAD 여부, 문합 수, 채취법, 인공심폐 사용을 별도 확인함. 원위부 문합 1개가 전통적 MIDCAB을 자동 의미하지 않음.

RA-MIDCAB / TECAB

RA-MIDCAB은 로봇 내흉동맥 채취 후 소절개 직접 문합임. TECAB은 문합까지 완전 내시경으로 시행함. STS의 Robot Used는 일부 단계 사용을 포함함.

HCR / OPCAB

HCR은 계획된 수술과 PCI의 조합 전략임. OPCAB은 인공심폐 미사용을 뜻함. 각각 접근법 분류와 겹치므로 MICS 건수에 별도 합산하지 않음.

전환과 기관 확산

최초 접근법과 최종 완료 접근법을 구분함. STS 전환 변수에는 계획·비계획 전환이 포함됨. 기관 누적 도입 수와 해당 연도 실제 시행기관 수도 구분함.

명칭 원문 · STS 공식 코드 정의

국내 전망에 연결하는 분석틀

최소침습 수술량
= 해당 수술량 × 적격 환자 비중 × 실제 채택률
  • 판막·관상동맥·대동맥의 채택 경로를 분리함.
  • 전국 채택률 하나만으로 적격비중과 채택률을 각각 식별할 수 없음.
  • 해외 추세는 국내 가정의 방향·범위 검토에 사용함.
  • 기존 수술량에 반영된 인력 제약을 다시 곱하지 않음.
  • 현재 한국 전국 보급률을 외국 관측치로 대체하지 않음.
코호트 중복·출판연도 주의

유럽 다국가 자료와 참여국 연구, 동일 STS 기간의 하위 코호트는 겹칠 수 있음. 연구 간 합계 산출 금지. 최근 발행 리뷰의 숫자도 실제 관측연도를 다시 확인함.

국내 전망으로의 연결

해외 원문은 확산 가능성과 적용 확장, 프로그램 지속성의 근거를 보강함. 한국의 전국 현재 보급률, 적격 환자 수, 활동 집도의 절대 인원을 새로 식별하지는 못함.

06 · 국내 MICS 전환 가정

MICS 합성 가정의 적용

2025 시작점부터 임의 가정
이 블록의 MICS 비중은 전국 실측 보급률이나 회귀 적합치에 해당하지 않음. 2025 비중·상한·보급 속도를 직접 설정한 합성 가정. 선택 환자 연구나 KHVSR에서 전체 비중으로의 환산 없음.
해외 근거의 반영 방식

승모판의 확대, 관상동맥의 단계적 확산, 프로그램 중단·재개의 차이를 별도 경로로 해석함. 아래 계산은 기존 국내 수술량 × 전체 채택비중의 합성 가정을 유지함. 해외 관측치로 한국의 시작 비중을 재설정하지 않음.

상단 수술량 시나리오를 고정한 MICS 보급 가정 3개 비교. 합성 등가량과 실제 MICS 환자 수의 구분 필요.

07 · 집도 공급과 지속성

인력 지수 대비 상대 산출 요구

2025 = 100 · 명수 아님
2025 = 100, 단위 없는 상대지수
산출 요구지수 = 수술량 지수 ÷ 공급 지수 × 100. 실제 노동시간·부족 인원·FTE 또는 실현 가능한 처리능력 추정치에 해당하지 않음. 성인 집도자 지수와 전체 연령 수술자료의 범위 차이, 술식 구성·배분 고정 가정 포함.

수술량 전망에 공급 계수의 추가 곱셈 없음. 공급과 수술량 경로 사이의 긴장을 확인하기 위한 별도 진단값.

설치와 지속 운영의 구분

로봇 장비·누적 교육 인원·누적 도입기관은 현재 활동 집도 공급을 대체하지 못함. 최소 증례 확보, 팀 유지, 중단·재개를 함께 추적함. 국내 실제 집도의 절대 인원은 미확인 상태임.
