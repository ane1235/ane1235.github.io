# 참고 페이지 분석과 적용

- 원문: [AIスライドを「クリックで深掘りできる資料」にしてみた。動かし方は6つの構造で決まる【保存版】 — うちた](https://note.com/uchita_success/n/nf8711b1dba37)
- 공개 본문 확인: 2026-10-01. 유료 첨부자료는 열람하지 않음.

1. **정보 구조**
   - 전체 조망에서 주제별 화면으로 이동.
   - 판단을 큰 수치·주요 도표로 제시하고, 상세 근거는 클릭 패널에 배치.
   - 페이지별 핵심 조작 하나를 정보 구조에 맞춰 부여.
2. **조작 방식**
   - 카드로 이동, 비교 기준 전환, 근거 패널.
   - 키보드 화면 이동·전체 조망·닫기.
   - 정적 보기와 동작 축소 설정 지원.
3. **이번 보고서 적용**
   - 6화면: 검토 방향 → DLT 기준 → 우선 후보 → 2순위 → 일회용 → 국내 공급.
   - DLT 크기 선택, 후보 모델 선택, 활용 영역 선택, 국내 제조사 선택.
   - 숫자·제품 사양은 기존 보고서 범위만 사용. 새 임상 수치·경제성 추산은 생성하지 않음.
   - 기존 청색·청록색 유지, 큰 한글 본문, 반응형 배치. 작은 고정 캔버스 축소 방식은 사용하지 않음.
   - 키보드: 좌우·Space·1–6·O·Esc. `#static`은 전체 정적 읽기.
4. **적용 범위**
   - 원문의 상호작용 원칙을 참고하여 독자 구현.
   - 원문 프롬프트·예제 코드는 지시문으로 실행하거나 복제하지 않음.
   - 유료 자료·자산·예시의 데이터는 사용하지 않음.
