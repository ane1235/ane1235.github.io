2. 사용할 브라우저에 설치

Chrome 도우미 설치

Chrome 도우미 받기

  1. ZIP의 압축을 풀고 Nyangsta-Chrome 폴더를 계속 보관할 위치로 옮깁니다. 설치한 뒤에도 이 폴더를 지우지 마세요.
  2. Instagram에 로그인할 Chrome 프로필에서 주소창에 chrome://extensions를 입력합니다.
  3. 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다를 누릅니다. manifest.json이 들어 있는 Nyangsta-Chrome 폴더를 선택합니다.
  4. 도우미가 켜져 있는지 확인한 뒤 아래의 도우미 연결 확인으로 진행합니다.

Chrome 공식 설치 안내

Safari 도우미 설치

이 Mac에 Xcode가 필요합니다. 아래 ZIP은 앱 프로젝트를 만드는 준비 도구이며, 서명·공증 완료 앱은 아직 제공하지 않습니다.

Safari 앱 준비 파일 받기

  1. Xcode를 설치하고 한 번 열어 초기 설정을 마칩니다. Xcode의 Settings → Locations → Command Line Tools에서 설치한 Xcode를 선택합니다.
  2. ZIP을 다운로드 폴더에 풀고 Mac 터미널에서 아래 한 줄을 실행합니다. 
    /bin/zsh "$HOME/Downloads/Nyangsta-Safari-App/Prepare-Safari.command"
    다른 곳에 압축을 풀었다면 그 폴더의 Prepare-Safari.command 경로를 사용하세요.
  3. 터미널에 프로젝트 생성 완료가 표시되고 Xcode에 냥스타저장 프로젝트가 열렸는지 확인합니다. Open / Clone / New Project만 보이면 터미널에 표시된 프로젝트를 직접 엽니다.
  4. Xcode의 Settings → Apple Accounts에서 본인 계정을 확인합니다. 앱과 확장 대상 각각의 Signing & Capabilities에서 Automatically manage signing과 같은 Team을 설정합니다. macOS 앱과 My Mac을 선택해 Run으로 실행합니다.
  5. 실행과 서명을 확인한 앱을 응용 프로그램 폴더에 복사하고 그 복사본을 실행합니다. Xcode의 Products에서 앱을 우클릭해 Show in Finder로 찾을 수 있습니다. 같은 이름의 앱이 있으면 기존 버전을 확인한 뒤 교체합니다.
  6. Safari → 설정 → 확장 프로그램에서 도우미를 켭니다. 사용하는 Safari 프로필과 instagram.com, 선택한 서버 사이트의 접근을 허용합니다. 아래에서 연결을 확인한 뒤 Safari를 완전히 종료·재실행해 연결이 유지되는지도 확인합니다.

준비 도구 v3는 새 프로젝트의 앱·확장 설정을 자동으로 맞춥니다. 도우미는 0.2.0이며 Tailscale과 LAN을 함께 지원합니다. 서명 조건과 실제 실행은 설치할 Mac에서 확인해야 합니다.

Apple 실행 안내 · Apple 서명·배포 안내

Xcode 없이 임시 검증용 도우미 사용

Safari 18.4 이상에서 기능을 잠깐 확인할 때 사용합니다. 임시 설치는 Safari를 종료하거나 24시간이 지나면 삭제됩니다. 계속 사용하려면 위 앱 설치 순서를 따르세요.

Safari 임시 검증용 도우미 받기

  1. 압축을 푼 뒤 Safari의 설정 → 고급 → 웹 개발자용 기능 보기를 켭니다.
  2. 설정 → 개발자 → 임시 확장 프로그램 추가(Add Temporary Extension…)에서 manifest.json이 있는 Nyangsta-Safari 폴더를 선택합니다. macOS가 인증을 요청하면 해당 창에서 처리합니다.
  3. 확장과 현재 프로필을 켜고 Instagram 및 선택한 서버 사이트 접근을 허용합니다. Safari에도 Instagram 로그인이 필요합니다.
기존 Safari 프로젝트의 오류 진단·수정

새 준비 도구에는 이전 모듈·스토리보드·Debug 라이브러리 설정 수정이 포함돼 있습니다. 새 Mac에서 오류가 나면 먼저 오류 문구와 터미널의 프로젝트 생성 경로를 확인하세요.

기존 프로젝트 진단·수정 도구 받기

진단 모드 --diagnose-extension은 앱·확장 등록과 서명을, --diagnose-seal은 서명 규칙을 확인합니다. 파일이나 설정을 바꾸지 않습니다. 도구의 기본 경로는 이전 Mac용이므로 다른 Mac에서는 실제 프로젝트 폴더를 지정해야 합니다.

모듈 충돌의 --fix-collision, Debug 라이브러리 서명 실패의 --fix-debug-dylib는 해당 오류가 확인된 기존 프로젝트용입니다. Xcode를 저장·종료한 뒤 사용하며 원본을 백업합니다. 수정 후 Product → Clean Build Folder → Run과 서명·연결 확인이 필요합니다. Debug 라이브러리를 끄면 해당 타깃의 Xcode Previews는 사용할 수 없습니다.

3. 연결 확인 후 저장

설치한 브라우저에서 Instagram을 열어 로그인하고, 같은 프로필로 아래 링크를 엽니다.

선택한 서버 https://kayenpc.tail730e13.ts.net:8443/

도우미 연결 확인 냥스타저장 열기

연결 확인은 Instagram을 조회하거나 다운로드 작업을 만들지 않습니다.

도우미 연결됨을 확인하면 웹앱에 링크를 입력하고 파일 준비하기 → 내 기기에 저장을 선택합니다. 스토리는 같은 브라우저의 Instagram 탭을 함께 열어 두세요.

연결되지 않을 때
  • Tailscale은 이 Mac에서 켜져 있어야 하며, LAN은 서버와 같은 로컬 네트워크에 연결돼 있어야 합니다.
  • 도우미를 설치한 브라우저 프로필인지 확인하고 웹앱을 새로고침합니다.
  • Safari는 확장 설정에서 현재 프로필과 Instagram·선택한 서버 사이트 접근을 확인합니다.

다른 Mac의 실제 설치·LAN 다운로드는 해당 기기에서 확인해야 합니다.

도우미는 비밀번호나 로그인 쿠키를 읽어 전송하지 않습니다. 선택한 개별 스토리의 파일 정보를 웹앱에 전달하며, 준비된 파일은 브라우저로 내려받습니다.
