Instagram에 로그인된 브라우저로 스토리 저장

도우미를 설치하면 냥스타저장에 스토리 링크를 입력할 때 같은 브라우저 프로필의 Instagram 로그인을 사용합니다. Instagram 탭을 함께 열어 두세요.

macOS Chrome

  1. Chrome 도우미 다운로드 후 압축을 풉니다. 이 폴더는 설치 후에도 보관해 주세요.
  2. Instagram에 로그인된 Chrome 창에서 chrome://extensions를 엽니다.
  3. 오른쪽 위 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다를 선택합니다. 압축을 푼 폴더 안에서 manifest.json이 있는 폴더를 선택합니다.
  4. 같은 프로필에서 Instagram을 열어 로그인 상태를 확인합니다. 냥스타저장 페이지를 새로고침한 뒤 개별 스토리 링크를 입력하고 파일 준비하기를 누릅니다.

macOS Safari · 저장 기능 검증

Safari 18.4 이상에서 설치할 수 있는 검증용 도우미입니다. Chrome 도우미와 별도로 설치하고, Safari에서도 Instagram에 로그인해 주세요.

  1. Safari 임시 검증용 도우미 다운로드 후 압축을 풉니다.
  2. Safari → 설정 → 고급 → 웹 개발자용 기능 보기를 켭니다. 개발자 탭에서 임시 확장 프로그램 추가(Add Temporary Extension…)를 선택합니다. macOS가 인증을 요청하면 해당 창에서 처리합니다.
  3. manifest.json이 들어 있는 Nyangsta-Safari 폴더를 선택합니다. 확장 프로그램 설정에서 도우미를 켜고 사용하는 Safari 프로필에도 활성화합니다.
  4. 웹사이트 접근 권한에서 instagram.com과 사용하는 냥스타저장 사이트(ane1235.github.io 또는 kayenpc.tail730e13.ts.net)를 허용합니다.
  5. 같은 Safari 프로필에서 Instagram에 로그인하고 냥스타저장 페이지를 새로고침합니다. 개별 사진·영상 스토리 링크를 입력해 파일 준비하기 → 내 기기에 저장을 실행합니다.

설치 후 도우미 연결 확인을 먼저 열어 주세요. 이 확인은 Instagram을 조회하거나 다운로드 작업을 만들지 않습니다.

임시 설치는 Safari를 종료하거나 24시간이 지나면 삭제됩니다. 사진·영상 스토리 저장은 확인했으며, 재실행 후에도 유지되는 앱 설치 방식은 아래 순서로 준비합니다.

설정 이름은 Safari 언어·버전에 따라 다를 수 있습니다. Apple 공식 설치 안내

Safari 앱 프로젝트 준비

Mac에 Xcode를 설치하고 첫 실행 설정을 마쳤다면 다음 단계로 진행하세요. 이 파일은 Xcode 프로젝트를 만드는 준비 도구입니다. 앱 서명·설치와 Safari 재시작 확인은 프로젝트를 만든 뒤 진행합니다. 현재 생성된 앱의 실행 오류를 수정 중이며, 다른 Mac에서 바로 설치할 수 있는 서명·공증 완료 앱은 아직 제공하지 않습니다.

  1. Safari 앱 프로젝트 준비 파일 다운로드 후 압축을 풉니다. 다운로드 폴더에 Nyangsta-Safari-App 폴더가 생깁니다.
  2. Mac의 터미널을 열고 아래 명령을 실행합니다. 압축을 다른 곳에 풀었다면 그 폴더 안의 Prepare-Safari.command 경로를 사용하세요. 
    /bin/zsh "$HOME/Downloads/Nyangsta-Safari-App/Prepare-Safari.command"
  3. 터미널의 프로젝트 생성 완료 경로와 Xcode 왼쪽의 냥스타저장 프로젝트 표시를 확인하세요. Open / Clone / New Project만 보이는 시작 화면이라면 터미널 결과부터 확인합니다. 오류가 나오면 해당 문구를 알려주세요. 생성한 프로젝트와 기록은 표시된 새 폴더에 보관됩니다.
프로젝트 생성 뒤 서명·설치 순서

Xcode의 Settings → Apple Accounts에서 본인 Apple 계정을 확인합니다. 프로젝트의 앱과 확장 대상 각각에서 Signing & Capabilities → Automatically manage signing → Team을 설정합니다. 화면에 Set Up Signing이 보이면 해당 안내를 따라가세요.

Mac 앱을 선택하고 실행 대상을 My Mac으로 정한 뒤 실행합니다. 서명 오류가 나면 정확한 문구를 확인하고, 성공하면 Safari에서 앱에 포함된 도우미를 활성화합니다. 마지막으로 Safari를 종료·재실행한 뒤 도우미 연결과 저장을 확인합니다. 계정의 서명 조건과 재시작 후 유지 여부는 실제 Mac에서 확인해야 합니다.

Apple 서명·실행 안내

기존 Xcode 프로젝트의 실행 오류 수정

AppDelegate·ViewController의 Unknown class 오류를 확인한 기존 프로젝트용 도구입니다. 긴 명령을 붙여넣다가 터미널이 입력을 기다리면 먼저 Control+C로 취소하고 Xcode에서 실행을 중지하세요.

Safari 프로젝트 수정 파일 다운로드 후 Mac 터미널에서 다음 한 줄을 실행합니다.

/bin/zsh "$HOME/Downloads/Repair-Safari.command"

이 도구는 Downloads/Nyangsta-Safari-Project-20260918-102433의 원본을 백업하고 두 클래스의 모듈 참조를 수정합니다. 이미 수정됐으면 상태만 표시합니다. 완료 후 Xcode의 Product → Clean Build Folder → Run으로 앱 실행을 확인하세요. 이 도구의 완료 메시지만으로 앱 설치나 Safari 재시작 유지가 확인되는 것은 아닙니다.

스토리의 계정·항목 ID·사진 또는 영상·게시 시각을 확인한 뒤 파일을 준비합니다. 요청 제한이나 추가 인증이 나오면 자동 반복하지 않습니다.

도우미는 비밀번호나 로그인 쿠키를 읽어 전송하지 않습니다. 준비된 파일은 웹앱에서 내려받습니다. iPhone·iPad 단축어 개선은 Chrome과 Safari 웹앱 검증 뒤에 진행합니다.
